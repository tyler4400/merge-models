# 合成大模型 — 玩法简报

一句话：侧视容器里往下掉玻璃球。两颗同级合成下一级。第一次做出 T-800 即通关，之后可以继续刷分。有球在顶线之上**且已静止**约 2 秒才算失败。休闲局，不是刷分肝游。

## 合成链（1 → 10）

豆包 → 元宝 → Qwen → Kimi → DeepSeek → Gemini → Grok → ChatGPT → Claude → **T-800**

- 通关 = **第一次**做出 T-800。
- 通关后可继续玩；再做出的 T-800 只加分，不再弹第二次胜利窗口。
- 两颗 T-800 相碰：两颗一起消失，+5000 分，**没有 11 级**。

## 投放

- 玩家只能投放 1–4 级球。权重 **35 / 30 / 20 / 15**。
- 下落前可左右移动。有幽灵预览。
- 只预览 **下一颗**（NEXT）。
- 上一颗还在滚动 / 未静止时，不能再投。

## 球体

- 3D 玻璃球（不是扁圆片）。
- 表面贴官方图标 + 短名。
- 体积随等级增大；T-800 明显最大。
- 物理滚动、挤靠。
- 同级接触就地合成，并轻微上弹，方便连击。

## 容器

- 不要太窄；半径增长不要太猛。
- 顶部警戒线。靠近时：线变红 + 轻警报。
- **失败条件**：有球越过警戒线 **并且** 保持静止约 2 秒。弹一下又掉回去不算失败。

## 胜利 / 失败

**胜：** 第一次 T-800 → 短庆祝 → 结算（分数、用时、剩余锤子）→「继续刷分 / 再来一局」。
继续：计时和分数接着走，不再打断。

**负：** 越线失败 → 冻结 → 结算 → 再来一局。

## HUD

- 当前分数 + 已用时间（**第一次投放后**才开始计时）。
- 时间只展示，倒计时不会判负。
- 右上角下一颗预览。
- 底部道具栏：一把锤子 + 剩余数量数字。
- 合成时中央 toast 显示合成名，淡出。
- 标题「合成大模型」。

## 计分

| 事件 | 分数 |
|---|---|
| 合成到第 n 级 | `10 * n * n` |
| 同一次投放的连击 | 从第 2 次合成起，每次额外 ×1.25 |
| 第一次做出 T-800 | +3000，再加 `max(0, 2000 - 秒数 * 8)` |
| 两颗 T-800 相碰消失 | +5000 |
| 锤子砸球 | 0 分 |

## 锤子（3 把）

- 点锤子 → 进入瞄准 → 点一颗 **已静止** 的球 → 球消失，玻璃碎裂 + 碎片 + 音效。
- 邻球会塌下来（可能连锁合成，也可能把别的球顶上去 — 有风险）。
- 不能砸手里拿着的 / 正在下落的球。
- 点空处取消（不消耗锤子）。
- 砸的过程中不能再投新球，直到大致静止。

## 明确不做

- 持久进化图鉴
- 商店
- 第二种道具
- 限时失败
- 第 11 级

## 操作

**手机：** 手指拖动移动手持球；松手投放；锤子按钮够大；390px 宽 overlay 可读；画布禁止滚动 / 缩放。

**桌面：** A/D 或方向键或鼠标移动；点击 / 空格投放。

音频在第一次手势时解锁。

## 视觉

明亮高对比，不要深色。浅色房间、深描边 HUD、有质感的玻璃球。警戒线用琥珀 / 红。锤子在底部用数字显示数量。
