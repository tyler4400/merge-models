# 训练大模型 — 玩法简报

一句话：侧视容器里往下掉玻璃球。两颗同级合成下一级。第一次做出 T-800 即通关，之后可以继续刷分。休闲局，不是刷分肝游。

开场：「训练大模型，同级的会练成下一代。看你能不能练出统一全世界的大模型。」

## 合成链（1 → 10）

豆包 → 元宝 → Qwen → Kimi → DeepSeek → Gemini → Grok → ChatGPT → Claude → **T-800**

- 通关 = **第一次**做出 T-800。
- 通关后可继续玩；再做出的 T-800 只加分，不再弹第二次胜利窗口。
- 两颗 T-800 相碰：两颗一起消失，+5000 分，**没有 11 级**。

## 投放

- 玩家只能投放 1–4 级球。权重 **35 / 30 / 20 / 15**。
- 下落前可左右移动。预览球半透明，外圈用该阶描边色。
- 只预览 **下一颗**（NEXT）。
- **可快速连点下落**，不必等上一颗停稳。
- 点击处的 X 下落（不镜像）。出生点在警戒线上方。
- 手机倾斜可轻微拨动罐里已落下的球。

## 球体

- **2D 圆片**（不是 3D 玻璃球）：图标铺满圆，外圈分阶色。
- 滚动时图标跟着转。
- 体积随等级增大；T-800 明显最大。半径相对初版再缩约一成。
- 物理滚动、挤靠。
- 同级接触就地合成，并轻微上弹，方便连击。

## 容器

- 竖屏 390×844。HUD 顶栏、罐子淡 U（左右只留约 12px）、底栏一把剪枝剪。
- 第一关院子：木色浅底日光院子，不是黑边木箱。
- 顶部警戒线。堆住的球靠近时：线变红 + 轻警报。
- **警告**：刚落下 0.8 秒内不计；还在下落（`vy < -0.25`）的球不亮红线。
- **失败**：有球越过警戒线并保持约 2 秒。刚落下穿过红线不算。弹一下又掉回去不算。

## 胜利 / 失败

**胜：** 第一次 T-800 → 短庆祝 → 结算（分数、用时、剩余剪枝剪）→「继续刷分 / 再来一局」。
继续：计时和分数接着走，不再打断。

**负：** 越线失败 → 冻结 → 结算 → 再来一局。

## HUD

- 当前分数 + 已用时间（**第一次投放后**才开始计时）。
- 时间只展示，倒计时不会判负。
- 右上角下一颗预览。
- 底部道具栏：一把**剪枝剪** + 剩余数量数字（×3 不烤进图标）。
- 合成时中央 toast 显示合成名，淡出。
- 标题「训练大模型」：气泡立体字 + 图标圆片装饰，无树叶。

## 计分

| 事件 | 分数 |
|---|---|
| 合成到第 n 级 | `10 * n * n` |
| 同一次投放的连击 | 从第 2 次合成起，每次额外 ×1.25 |
| 第一次做出 T-800 | +3000，再加 `max(0, 2000 - 秒数 * 8)` |
| 两颗 T-800 相碰消失 | +5000 |
| 剪枝剪砸球 | 0 分 |

## 剪枝剪（3 把）

- 点剪枝剪 → 进入瞄准 → 点一颗 **已落地** 的球（`dropAge ≥ 0.3s`）→ 球消失，2D 碎裂特效 + 玻璃珠音。
- 邻球会塌下来（可能连锁合成，也可能把别的球顶上去 — 有风险）。
- 不能砸手里拿着的 / 正在合成的球。
- 点空处取消（不消耗次数）。点到还不能砸的球，继续瞄准。
- 砸的过程中不能再投新球，直到大致静止。

## 明确不做

- 持久进化图鉴
- 商店
- 第二种道具
- 限时失败
- 第 11 级

## 操作

**手机：** 手指拖动移动手持球；松手投放；剪枝剪按钮够大；390px 宽 overlay 可读；画布禁止滚动 / 缩放。

**桌面：** A/D 或方向键或鼠标移动；点击 / 空格投放。

音频在第一次手势时解锁。碰撞是玻璃珠互撞，不要正弦哔声。

## 视觉

白 / 米色圆角条、气泡立体字、软阴影。禁止厚黑描边和深色硬框。罐子淡 U，口不要做成朝镜头的深色大圆圈。第一关院子用木色浅底。警戒线用琥珀 / 红。
